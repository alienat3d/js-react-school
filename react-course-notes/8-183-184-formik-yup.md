*[«Formik», «Yup» и работа с формами любой сложности (183-184)]*

? 183.0 Рассмотрим ещё одну библиотеку для создания форм "Formik" и в целом рассмотрим варианты создания форм с помощью готовых решений. Есть множество других решений, просто "Formik" самая популярная библиотека для создания форм (на момент создания курса). 
? 183.1 Но есть также "Final Form", которая работает с Redux (подход, когда все данные хранятся в отдельном хранилище, как в первом pet-проекте курса "список сотрудников", но за пределами интерфейса и без пропсов). Изучать её пока здесь не будем, т.к. мы ещё не прошли Redux (а ещё этот подход хотя и хорош для небольших приложений, но может вызвать ухудшение производительности на средних и крупных проектах из-за обновления всего хранилища при каждом введённом символе, если хранилище действительно объёмное).
? 183.2 Ещё один подход это поместить весь функционал для форм в отдельных хук и использовать его в проекте. Для этого также есть готовое решение "React Hook Forms" (на самом деле это весьма удачное решение, которое может даже показывать большую производительность).
? 183.3 Что касается валидации формы, мы можем использовать как собственные проверки и регулярные выражения, так и воспользоваться отдельными библиотеками для этого, например, разработчики Formik сами рекомендуют использовать их библиотеку в связке со сторонней библиотекой «Yup». Для тренировки мы используем и её тоже.

Рассмотрим принципы использования на примере компонента мини-проекта формы для благотворительности, сделанной на основе библиотеки «Formik»: [\projects\mini-projects\formik-for-charity\src\FormikWithHook.js]
